# Lexicon

One word per concept. A banned word is refused by the check in every file this repository generates.

| concept | word | banned |
|---|---|---|
| the ordered list a manager owns | roadmap | plan, backlog, sprint, epic |
| a point a manager reports upward | milestone | phase, checkpoint |
| a unit executed without reporting | work package | task, ticket, story, subtask |
| a set of packages that run in parallel inside one milestone | workset | batch, wave, stage |
| an agent that keeps a directory, a document and a roadmap | manager | role tier, agent type, supervisor |
| an agent that executes one package in its parent's directory | worker | subagent, executor, task runner |
| the three-field upward message | report | update, summary, status report |
| the thing that must be observed before a step is done | evidence | proof, citation |
| the point where work stops for the person | gate | approval step, signoff |
| the record of where each old rule went | ledger | mapping, inventory |
| the file a role reads | guide | policy, prompt, rules file |
| one entry in this corpus | rule | policy node, entry, item |

## Words the field owns

A version, a hash, a path, a port, a seed, a temporary path, an inbox, a node of a graph, and the
ordinary names of the tools. "Node" names a point in a roadmap graph and nothing else; a rule in
this corpus is a rule.

## The person's words

A word the person introduced is kept in their spelling and their language. A word they use loosely
is corrected once, at the point where it would otherwise be repeated, and the correction is recorded
as an expression gap.
