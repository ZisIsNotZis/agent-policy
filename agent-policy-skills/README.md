# Agent Policy Skills

These are optional, on-demand procedural playbooks referenced by `LAW.md`. Load a skill when its description matches the work. They supplement the policy; they do not override the Goal, explicit constraints, or LAW. The standard scope-record templates are installed alongside the skills at `../templates/`.

| Skill | Use when |
|---|---|
| `research-and-discovery` | Uncertain, novel, research-heavy, creative, or potentially misframed work |
| `project-framing-and-validation` | Understanding user needs and defining success |
| `planning-and-decomposition` | Delegation, workstreams, dependencies, resource bounds, concurrency, and adaptive planning |
| `documentation-and-ssot` | Project memory, standard records, documentation structure, and authoritative sources |
| `engineering-quality` | Software implementation, testing, debugging, independent verification, and review |
| `release-and-delivery` | User-facing milestones, packaging, publishing, and reachability |
| `repository-hygiene` | Repository structure, naming, indexing, and cleanup |
| `safe-migration` | Broad refactors, schema changes, and structural/data migrations |

`LAW.md` defines durable invariants and role boundaries. Runtime configuration and enforcement belong to the harness/deployment. Skills provide task-specific procedures; project records describe the current project.
